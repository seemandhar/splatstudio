# SplatFields (Mihajlovic et al., ECCV 2024) — implementation spec

arXiv 2409.11211 · official code https://github.com/markomih/SplatFields (MIT; 3DGS rasterizer
under the Inria licence) cloned into `source/code/` (read, never run). LaTeX in `source/latex/`.

## 1. Method summary
- Sparse-view 3DGS overfits because splat attributes have no spatial autocorrelation (Moran's I).
- SplatFields predicts every splat attribute from neural fields of its (anchor) position:
  a tri-plane generated by a deep-image-prior CNN from fixed noise, sampled bilinearly at the
  anchor, refined by a tiny MLP, then MLP fields for position offset, scale, opacity, rotation
  and colour. Only the networks are optimised; anchors move only through densification.
- Extra losses: splat L2-norm regulariser on predicted centres; mask loss on object scenes.
- Initialised from the point cloud of a (sparse-view) 3DGS run; networks are discarded after
  training (rendering = plain 3DGS with the baked attributes).
- 4D extension (time-conditioned ResField MLPs, flow field) — **out of scope** (static only).

Contributions
- **C1 Neural splat fields** (§4 "Neural splat fields", supp. B.2): MLP fields
  f_Θ (deform), f_c, f_s, f_α, f_O predict attributes from PE(position) ⊕ feature.
- **C2 Deep structural prior / tri-plane CNN generator g_θ** (§4 "Deep structural prior",
  Eq. 6, supp. B.2).
- **C3 Splat norm regularisation** (§4, supp. Eq. A.2, λ3 = 0.01).
- (protocol) mask loss λ2 = 0.1 for object scenes (supp. Eq. A.2), visual-hull init, 3DGS
  stage-1 point cloud.
- C4 4D extension (§4 "4D reconstruction") — not implemented.

## 2. Equations
Eq. 6: `\mathbf{F} = g_{\theta}(\mathbf{\epsilon}) \in \mathbb{R}^{3 \times H \times W \times l}`
— three planes, each from its own decoder with its own fixed noise ε ∈ R^{8×20×20}.

Feature: `\mathbf{f}_k` = concat of bilinear samples of the xy, yz, zx planes at p_k
(code: `F.grid_sample(planes, coord)` with default align_corners=False, zero padding;
plane order xy, yz, zx, coord pairs (x,y),(y,z),(z,x)), then `Linear(48,48)-ReLU-Linear(48,48)`
(code: `mlp_refine_feat`).

Eq. 7: `\hat{\mathbf{p}}_k = f_{\Theta}(\mathbf{p}_k, \mathbf{f}_k)` — code:
`xyz_can = xyz + deform_weight * mlp_deform(xyz, f)` (deform_weight 1, residual).
Then `s = mlp_scale(p̂, f) + exp(base_log_scale)` (code train.py `ret['scales'] + scaling`),
`α = mlp_opacity(p̂, f)` (sigmoid), `q = normalize(mlp_rotation(p̂, f))`,
`c = mlp_rgb(p̂, f)` (sigmoid; **view-independent** in the code default,
`use_view_dep_rgb=False`; the paper says view-dependent).

Loss (supp. Eq. A.2):
`\mathcal{L} = (1-\lambda_1)\mathcal{L}_1 + \lambda_1 \mathcal{L}_{\text{D-SSIM}} + \lambda_2 \mathcal{L}_{\text{MASK}} + \lambda_3 \mathcal{L}_{\text{norm}}`
λ1 = 0.2, λ2 = 0.1 (Blender), λ3 = 0.01 (static). L_MASK = L1(clamp(rendered alpha,0,1), GT
alpha); L_norm = mean_k ||p̂_k||_2 (code: `means3D.norm(dim=1).mean()`).

GeneralMLP (code utils/time_utils.py): `net = [Lin(in,h)] + [Lin(h or h+in, h) × D] + [Lin(h,out)]`,
activation (leaky_relu) applied after **every** layer including the last, then the output
activation; after layer index i ∈ skips the input `[PE(x), f]` is concatenated.
PE: NeRF embedding with include_input, freqs 2^0..2^(L-1), [x, sin, cos] order per freq.

## 4. Schedules
SH degree +1 per 1000 (stage 1 only). Network LR exponential over 40k. Densification over the
whole run. No warm-up for static scenes (warm_up -1).

## 5. Builds on
3DGS (Inria codebase, ingra14m depth rasterizer). Kept: L1+D-SSIM, 3DGS clone/split rules
applied to the anchors, random view sampling with replacement (code never pops the stack).

## 6. Protocol (Blender few-view)
- Scenes as `nerf_synthetic` (Toy = lego). World scaled by 2/model_scale
  (chair 2.1, drums 2.3, ficus 2.3, hotdog 3.0, lego 2.4, materials 2.4, mic 2.5, ship 2.75).
- Train views: `KMeans(n_views, random_state=0)` on the 100 train camera centres, nearest
  camera to each centre, sorted (dataset_readers.py:679). n_views ∈ {4,6,8,10,12}.
- Test: all 200 `transforms_test.json` views, 800×800, white background, images composited
  `rgb·a + (1−a)` and truncated to 8 bit (`np.byte` cast).
- Metrics: per-image PSNR on 8-bit PNG renders, averaged; SSIM (Mip-NeRF style) ×100;
  LPIPS-VGG ×100.
- Pipeline: (1) 3DGS stage-1 run (= the paper's 3DGS row), (2) SplatFields from its cloud.
- DTU 3-view (pixelNeRF split, 2DGS-preprocessed DTU, `-r 2`, mask loss) — not reproduced.

## 7. Ambiguities
- Paper vs code architecture depths/PE levels and view-dependent colour differ; code used.
- `scales = MLP + exp(base)` can be negative; covariance uses s s^T so the sign is irrelevant.
- Clone duplicates the anchor exactly; both clones get identical network outputs.
- Hull projection divides by clip-z, not clip-w (dataset_readers.py) — reproduced in prep.
- KMeans selection depends on the scikit-learn version (official env: py3.7 → sklearn ≤1.0,
  n_init=10).
